# Oway templates
Created: 2026-11-15T12:30:00Z · Last edited: 2026-11-16T10:00:00Z

Blank files every Oway file starts from. Each one uses the header from [Rules](../rules.md#file-format-the-rule). Project, milestone and slice files always start with the goal, what you get, and the proof you will have; then the details.

| Template | Used for |
| --- | --- |
| [Project](project.md) | One project, short, with links to the five spines |
| [Spines](spines/) | The five parts of a project: [intent](spines/01-intent.md), [objects](spines/02-objects.md), [experience](spines/03-experience.md), [architecture](spines/04-architecture.md), [delivery](spines/05-delivery.md) |
| [Milestone](milestone.md) | One milestone, build or business |
| [Slice](slice.md) | One slice, its start agreement and its Git plan |
| [Proof matrix](proof-item.md) | The frozen list of proof items of one slice |
| [Pull request](pull-request.md) | The body of one pull request: problem, change, scope, verification, agent |
| [Keeper finding](keeper-finding.md) | One finding sent by a keeper |
| [Team](team.md) | One team of a project: members, links to cards, overrides |
| [Role card](role-card.md) | One agent |
| [Decision (ADR)](adr.md) | One important decision |
| [Owner profile](profile.md) | The owner, written once at the first setup |
